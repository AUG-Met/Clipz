# Clipz

轻量级 Windows 剪贴板历史管理器。常驻系统托盘，自动记录文本、文件、图片。

- **Ctrl+F1** 唤出/隐藏
- 分类查看（全部/收藏/文本/链接/文档/媒体）
- 搜索、收藏、自动粘贴
- 备份/恢复数据
- 中英文双语、主题切换
- QuickLook 文件预览

[下载](https://github.com/AUG-Met/Clipz/releases) | [English](README.en.md)

## 开发

```bash
npm install
npm run tauri dev    # 开发模式
npm run tauri build  # 构建
```

**技术栈**: React 18 + TypeScript + Vite / Rust + Tauri v2 / SQLite
